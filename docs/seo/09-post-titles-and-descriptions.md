## A display bug (fixed 2026-10-29)

Anything saved through the admin with an ampersand, such as "Security & Compliance", was stored as `&amp;` and some pages then showed the letters "&amp;" on screen. Short text fields are now decoded when read, so every page, list and admin form shows the real characters. The webinar page that showed it now reads "Data Security & Compliance". Long `content` fields are deliberately left alone.
