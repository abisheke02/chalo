# 01 · Content for the 14 modules

_Written 2026-10-29. Every statement comes from facts already published on the site. Where a fact still needs the company, it is marked **[confirm]**. Target phrases are what a school would type; their search volumes are not yet verified (Ahrefs has no data access and Search Console is not live)._

## How to read each module

Each module has the same parts, so a visitor who reads one understands them all:

- **SEO:** the page title (45 characters or fewer, the brand is added after it), the meta description (110 to 160), the target phrases.
- **H1 and answer-first summary:** the summary is written so Google and AI assistants can quote it as it stands.
- **Open it and you'll see:** six concrete things, so the visitor feels the module without logging in.
- **Who uses it, works with, questions:** the people, the connections, the doubts.
- **Continue to:** the next step, so the page is never a dead end.

Tone: plain words, outcome first, written to a principal, owner or correspondent. No "ERP" without saying what it means on first use.
